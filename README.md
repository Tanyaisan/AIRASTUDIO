# AIRA Studio — Smart Device Prototype

เว็บต้นแบบภาษาไทยสำหรับจำลองการควบคุมกรอบรูปดิจิทัล AIRA ที่ผสานไฟ Ambient LED และระบบฟอกอากาศ ทุกการทำงานจำลองในเบราว์เซอร์และไม่เชื่อมต่อฮาร์ดแวร์หรือบริการภายนอก

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือเผยแพร่ทั้งโฟลเดอร์นี้ด้วยบริการ static hosting เช่น Vercel, GitHub Pages, Cloudflare Pages หรือ Netlify

## การควบคุม

- เลือก JPG, JPEG, PNG หรือ WEBP (สูงสุด 25 MB) แล้วจัดตำแหน่งในหน้าต่างครอป 16:9 ด้วยการลาก ซูม หรือสัมผัสสองนิ้ว ก่อนยืนยันหรือยกเลิก
- ปรับ Ambient LED เปิด/ปิด เลือกสีเต็มสเปกตรัมผ่านแผง HSV, ตัวเลือกสี หรือ HEX และปรับความสว่าง 0–100%
- เลือกแสงคงที่ หายใจ รุ้ง พัลส์ หรือวนสี พร้อมปรับความเร็วและสีสำหรับโหมดวนสี
- เปิด/ปิดระบบฟอกอากาศและเลือกระดับแรงลม เงียบ ปกติ หรือแรง เพื่อดูภาพจำลองการไหลเวียนอากาศ
- รีเซ็ตการตั้งค่ากลับเป็นภาพและค่าตั้งต้น

ข้อมูลอากาศที่แสดงในโหมดสาธิตเป็นค่าจำลอง ไม่ได้อ่านจากเซนเซอร์ และไม่มีการเชื่อมต่ออุปกรณ์จริง

## Smart Air Frame demo features

- Smart Display Gallery: นาฬิกาตามเวลาท้องถิ่น, แดชบอร์ด PM2.5/PM10 ตัวอย่าง, ปฏิทินตัวอย่าง, สภาพอากาศตัวอย่าง, คำคม และสมาร์ตแดชบอร์ด โดยเลือกเพื่อแสดงในหน้าจอกรอบได้ทันที
- Sound & Alerts: เสียงแจ้งเตือนแบบสั้นผ่าน Web Audio ปิดเป็นค่าเริ่มต้น เลือกเปิด/ปิดและปรับระดับเสียงได้ พร้อมทดสอบเสียง เตือนฝุ่นจำลอง และเตือนแผ่นกรอง
- Pet Mode และ Kitchen Mode: เลือกแรงลมจำลอง พร้อมตัวเลือก Auto สำหรับ Pet Mode และตัวจับเวลา 15, 30 หรือ 60 นาทีสำหรับ Kitchen Mode
- Eco Mode และ Night Mode: ปรับความสว่างหน้าจอ/LED ตั้งเวลาใช้งาน และหรี่ไฟหรือปรับแรงลมเงียบใน Night Mode
- AIRA Art Store: ชมภาพตัวอย่าง เปิดดูรายละเอียด ทดลองแสดงผลงานบนกรอบ เพิ่มรายการโปรด และปลดล็อกผลงานจำลองที่บันทึกใน local storage
- ค่าตั้งค่าและรายการในร้านค้าตัวอย่างบันทึกในเบราว์เซอร์เครื่องนี้ ไม่มีบัญชีหรือการชำระเงินจริง

ค่าฝุ่น สภาพอากาศ การแจ้งเตือน และสถานะทั้งหมดเป็นการสาธิตเท่านั้น ไม่มีเซนเซอร์ ระบบจ่ายเงินจริง หรือการเชื่อมต่อฮาร์ดแวร์จริง

## การนำทาง

แอปจัดเป็น 4 ส่วน: **หน้าหลัก** สำหรับพรีวิวและควบคุมด่วน, **หน้าจอ** สำหรับเลือกรูป/วิดเจ็ตและปรับเฉพาะสิ่งที่เลือก, **ควบคุม** สำหรับการตั้งค่าขั้นสูงและตารางเวลา, และ **AIRA Art Store** สำหรับดูผลงาน รายการโปรด และผลงานที่ปลดล็อกแล้ว บนมือถือใช้แถบนำทางด้านล่าง
